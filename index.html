Konfigurasi Supabase Cloud

Sinkronisasi data otomatis via database PostgreSQL

Hubungkan CatatYuk ke database Supabase gratis Anda agar data tersimpan aman di cloud dan dapat diakses dari perangkat manapun.

SQL Schema (Jalankan di SQL Editor Supabase): 
CREATE TABLE transactions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  type VARCHAR(10) NOT NULL,
  amount NUMERIC(15, 2) NOT NULL,
  category VARCHAR(50) NOT NULL,
  date DATE NOT NULL DEFAULT CURRENT_DATE,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE transactions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public All" ON transactions FOR ALL USING (true);
